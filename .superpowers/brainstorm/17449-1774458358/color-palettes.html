Chord Tone Color Palette

How should chord tones be colored on the fretboard? Compare three approaches.

A

2-Color (Current)

Core tones = cyan, Extensions = orange. Simple and clean.

Core (R, 3, 5, 6)
Extension (9, 11, etc.)
Non-chord
Pro: Instantly see "in the chord" vs "not in the chord." Clean, minimal.
Con: Can't tell root from 5th. Useful for guitarists, less so for steel players who think in chord functions.
B

5-Color Per Function

Each chord degree gets its own color. Root, 3rd, 5th, 7th, Extensions all distinct.

Root
3rd
5th
6th / 7th
Extensions
Non-chord
Pro: See exactly what function each note plays. Root pops, 3rd shows major/minor at a glance. Already defined in chordFunctionColors.ts.
Con: 5 colors + gray = 6 things to track. Red for 3rd conflicts with red for pedal-changed notes. Could feel busy on dense chords.
C

3-Color Hybrid (Recommended)

Root gets its own color. Core chord tones share a color. Extensions share a third. Best of both worlds.

Root
Core (3, 5, 6, 7)
Extensions (9, 11, 13)
Non-chord
Pro: Root always jumps out (most important for steel players). Core vs extension still obvious. Only 3 colors to learn. No conflict with red pedal highlights.
Con: Can't distinguish 3rd from 5th visually — but the note name label is right there.
