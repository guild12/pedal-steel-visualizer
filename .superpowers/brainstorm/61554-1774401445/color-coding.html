Chord Tone Color Coding

How color helps players see what pedals/levers contribute to the chord

Approach A: Color by Chord Function

Each note is colored by its role in the chord — root, 3rd, 5th, 7th, extensions. At a glance you see the harmonic "shape."

Approach B: Color by Source (Open vs Pedal-Altered)

Notes that come from the open tuning are one color. Notes that a pedal/lever changed are a different color, with a badge showing which control. Focus is on "what did the controls change?"

Simple — just shows what changed. But no chord function info at a glance.

Approach C: Combined — Chord Function Color + Pedal Badges

Best of both: note circles colored by chord function (root/3rd/5th/7th/extension), with small pedal/lever badges on notes that were altered. You see both "what role does this note play" AND "which control gave it to me."
